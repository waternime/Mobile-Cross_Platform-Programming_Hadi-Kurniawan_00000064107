# Week 11 - Supabase

Project Expo React Native untuk praktikum Modul 11. Aplikasi ini mengambil foto dari kamera, membaca geolokasi saat foto diambil, mengunggah foto ke Supabase Storage, lalu menyimpan `latitude`, `longitude`, dan `image_url` ke tabel Supabase.

## Supabase

Buat bucket Storage bernama `images`, lalu buat folder `camera` saat upload pertama. Buat tabel `photo` dengan struktur:

```sql
create table photo (
  id bigint generated by default as identity primary key,
  created_at timestamptz not null default now(),
  latitude text,
  longitude text,
  image_url text
);
```

Untuk praktikum dasar, aktifkan policy agar aplikasi bisa upload ke bucket `images` dan insert ke tabel `photo`.

## Run

```bash
npm install
npm start
```

Konfigurasi Supabase ada di `.env` dan client ada di `lib/supabase.ts`.
